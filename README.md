# 基金手账 · Android

个人使用的场外基金账本，原生 Java 界面 + SQLite，无账户系统、无云端持仓、无支付宝凭证。

## 云端开发

项目仓库：https://github.com/thlxl/fund-assistant

在 Codex Cloud 创建环境时选择本仓库，初始化命令填 `bash tools/setup-cloud.sh`。脚本会检查依赖、安装 Android SDK 并运行构建检查；安装缺失系统包需要 root 或免密码 sudo，下载依赖需要网络。配置检查通过后发布环境，再从手机选择该环境开始工作。

现有需求和验证边界见 CLOUD_HANDOFF.md、VALIDATION.md。Git 仓库不保存 APK、个人持仓或签名密钥；云端默认生成的调试密钥与本地不同，不能保证覆盖安装此前的 APK。

## 使用

1. 安装 `dist/fund-ledger-0.1.0-debug.apk`（Android 8.0 及以上）。这是自用调试签名包。
2. 在「持仓」添加基金代码、已确认份额、剩余持仓总成本和起始日期。起始日期当日及以前的交易视为已包含在快照中。
3. 更新净值，核实基金名称和净值日期；自动识别名称，资产分类与行业标签由你确认。
4. 在「定投」为基金设置每个交易日金额、开始日期和实际申购费率。应用自动生成计划，已发布净值可推算预计份额；未确认记录不计入正式资产。
5. 每月可在基金详情「批量核对定投与总持仓」填写截至指定日期的支付宝总份额与剩余成本，一次核对多笔定投。逐笔记录保留「汇总核对，逐笔为估算」标记，差异通过调整记录留档。也可在交易列表逐笔填写实际份额。扣款失败、基金停购等可跳过；需要更正日期时先跳过原定投记录，再单独录入正确日期的交易。
6. 在「我的」填写其他资产、负债、应急资金目标与配置目标。基金资产不要在其他资产中重复填写。
7. 定期导出 JSON 备份。恢复会覆盖当前账本，失败会回滚。CSV 是交易导出格式，不作为完整恢复文件。

## 记账口径

- 买入金额是包含费用的总支出；确认份额取实际记录。费用仅留档，不重复扣除。
- 定投份额估算采用 `金额 ÷ (1 + 百分比费率) ÷ 净值`，向下保留两位。该公式只适用于比例前端申购费；固定费用、后端收费、特殊折扣均须用实际份额修正。
- 卖出份额填正数，金额填扣费后净到账；剩余成本按卖出前的平均成本比例减少，不用于计算赎回费税务批次。
- 现金分红记金额，份额为 0；红利再投记新增份额，金额为 0，避免重复外部投入。
- 持仓调整记录填写份额及成本的增减，可为负数。存在调整或仅汇总核对时不显示累计收益，先核实历史现金流。批量核对只确认截至该日的总持仓，不代表每笔成交份额已知。
- 资产按最新已知单位净值计价，未计价基金明确提示。已确认持仓盈亏 = 市值 - 剩余成本，不是完整历史投资收益。
- 基金净值曲线未复权，不作为含分红收益曲线。当前未提供 XIRR、基准对比、收益预测或回测。

## 自动定投边界

内置[上交所 2026 年休市日历](https://www.sse.com.cn/disclosure/dealinstruc/closed/)，周末与已知休市日跳过，不顺延。其他年份仅生成工作日候选并提示核对。QDII、香港假期、基金单独暂停申购及支付宝扣款状态不在国内日历覆盖范围内。

同一计划同一天只能有一笔记录，重复启动不会重复累计。起始日期当天的定投不会重复生成。计划结束日包含在内；改金额或恢复计划需结束旧计划，从次日新建。尚未开始的计划可提前结束，相当于取消。

打开 App 时补齐遗漏记录；联网时每天尝试后台更新。后台受安卓省电限制，不保证准点，也不保证应用强制停止后继续运行。刷新净值与确认实际成交是两件事。

## 分析范围

- 按手动分类统计大类资产，不进行混合基金底层资产穿透。
- 目标比例偏离 5 个百分点、手动行业标签占比超过 30%、应急现金不足时提示检查。这些是可解释的提醒规则，不是投资买卖信号。
- 30 天定投资金需求、90 天固定价格配置投影。投影假设资金从组合外流入，暂不扣费用，不预测投资收益。
- 暂未接入指数估值、基金经理变化、定期报告持仓重合、历史基准比较；不输出伪造的择时结论。

## 数据与隐私

行情来自天天基金公开 `pingzhongdata` 数据，已验证真实响应，但不是正式签约 API，无可用性承诺。仅解析 JSON 字段，不执行远端 JavaScript；请求只携带基金代码。失败保留旧数据，可手动录入基金公司或支付宝已公布净值。

持仓保存在应用私有 SQLite 中，禁用系统自动备份，不接云端 AI、广告或统计 SDK。导出备份与 CSV **未加密**；卸载会删除私有数据库。首次安装时无示例持仓。

## WSL 构建

开发环境：Ubuntu WSL2，JDK 17，Android SDK 35，Android Gradle Plugin 8.7.3，Gradle 8.9。

```bash
cd /mnt/d/private_project/fund-assistant
# 首次安装需要 Java 17 和 unzip；下载 Android SDK 与 Gradle，并接受 SDK 许可
bash tools/setup-wsl.sh
bash gradlew testDebugUnitTest assembleDebug lintDebug assembleDebugAndroidTest
```

工具链安装在 `~/.local/share/fund-assistant`；`local.properties` 保存本机 SDK 路径，不纳入版本控制。首次构建需联网下载依赖。SDK 许可属于 Google；setup 脚本仅用于已授权的本机环境。

单元测试验证费用估算、节假日、快照边界及超卖。安卓仪器测试验证 SQLite 去重、预计成交隔离、历史修改回滚、分红和备份恢复，使用独立测试数据库，不覆盖真实账本。

调试签名密钥位于 WSL 的 `~/.android/debug.keystore`。同一密钥构建的后续 APK 才能覆盖安装；请妥善保留密钥和账本备份，勿为升级随意卸载。
